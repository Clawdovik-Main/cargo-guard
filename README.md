# Cargo Guard

Учебный стенд системы контроля целостности поставляемой продукции.

Сервер: Python, REST, PostgreSQL. Фото серийного номера хранится файлом, в базе лежит путь.
Клиент: страница в браузере, HTML, CSS, JavaScript.

Запуск рассчитан на компьютер учебного стенда. Отдельный платный хостинг в задании не предусмотрен.

Каталог `server` - правила массы, запрет закрытия приёмки и журнал.
Каталог `client` - экран кассира и дашборд службы безопасности.
